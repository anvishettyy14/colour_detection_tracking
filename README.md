**Colour Detection & Tracking Using Python**

A real-time computer vision project that detects coloured regions in a webcam feed and tracks their positions using Python and OpenCV.

Features

- Real-time colour detection using a webcam.
- Detects colours such as red, blue, green, yellow, orange, purple, pink, brown, black, white, and grey.
- Displays a bounding box around the selected detected region.
- Shows the detected colour and its centre coordinates.
- Uses image processing techniques to reduce noise and improve detection.
- Smooth tracking to reduce flickering.

Technologies Used

- Python
- OpenCV
- NumPy
- Computer Vision
- Image Processing

Requirements

- Python 3.x
- A webcam
- OpenCV
- NumPy

Installation

Install the required libraries:

```bash
pip install opencv-python numpy
```

How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the Python script:

```bash
python object_tracking_single_colour.py
```

4. Allow access to your webcam.
5. Press **Q** to exit the application.

Project Objective

The objective of this project is to demonstrate real-time colour detection and position tracking using computer vision techniques.
